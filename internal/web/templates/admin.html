Joining

Discussion location

Songstead keeps comments here. Witmoot moves new comments to Witmoot, where each person needs a Witmoot account. Both lets people choose. Existing comments stay readable in every mode.

With Witmoot or Both, members can prepare a Witmoot discussion and review the draft there before posting. No API key is needed. Listening notes never leave Songstead, and private links still need permission to open.
